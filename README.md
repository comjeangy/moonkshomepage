# 문경순 디지털 교육 강사 홈페이지

기존 홈페이지의 디자인과 콘텐츠를 기준으로 처음부터 다시 작성한 정적 사이트입니다.
첫 번째 홈페이지의 보라색 테마·메인 이미지·섹션 구성을 유지하고, 두 번째 홈페이지의
Three.js 문서 회전 갤러리를 독립된 기능으로 구성했습니다.

## 실행과 배포

Node.js 22 이상에서 `npm run dev`를 실행한 뒤 http://127.0.0.1:8790/ 에 접속합니다.
설치할 npm 패키지와 별도의 빌드 과정은 없습니다. `index.html`을 파일로 직접 여는 대신
로컬 서버를 사용합니다. 브라우저 ES 모듈과 JSON 로딩을 위해 필요합니다.

GitHub Pages는 **main 브랜치 / 루트 폴더**를 배포합니다. `/moonkshomepage/` 하위 경로도
지원합니다. `BASE_PATH=moonkshomepage` 환경변수를 지정해 로컬에서 같은 경로로 확인할 수 있습니다.

`npm run check`는 내부 링크, 파일 참조, 모듈 문법, 자료 목록과 선택·검색 동작을 검사합니다.

## 구조

```text
index.html                     페이지의 시맨틱 마크업과 소개 콘텐츠
assets/
  images/                      메인·프로필·교육 현장 이미지
  evidence/                    개인정보 가림 처리된 자료와 작은 미리보기
  vendor/                      Three.js 원본 배포 파일과 MIT 라이선스
data/archive.json              57개 자료의 제목·분류·이미지 경로
src/
  main.js                      기능 시작점
  styles/
    theme.css                  색상·글꼴·폭 토큰
    global.css                 공통 규칙과 레이아웃 유틸리티
    home.css                   홈페이지 섹션별 디자인
  lib/dialog.js                확대창 열기·닫기와 포커스 복귀
  features/archive/
    index.js                   검색·분류·미리보기·확대창 연결
    state.js                   렌더링과 독립된 자료 선택 모델
    scene.js                   Three.js 회전·드래그·키보드 제어
    archive.css                갤러리와 확대창 스타일
scripts/                       로컬 서버와 정적 파일 검사
tests/                         실제 자료를 이용한 상태 동작 검사
```

## 수정하는 방법

- 소개 문구·강의·경력·연락처: `index.html`의 해당 섹션을 수정합니다.
- 전체 색상·글꼴: `src/styles/theme.css`를 수정합니다.
- 자료 추가: `assets/evidence/`에 큰 이미지와 썸네일을 넣고 `data/archive.json`에 항목을 추가합니다.
  `id`는 중복 없이 지정하고 `category`는 기존 분류명을 사용하거나 새 이름을 지정합니다.
  분류 버튼과 개수는 목록에서 자동으로 만들어집니다. 목록 순서가 최초 표시 순서입니다.
- 자료 경로 예: `"image": "assets/evidence/0-01.webp"`.
- 메인 이미지는 `assets/images/ai-classroom.png`입니다. 교육 현장 사진에는 기존 얼굴 블러가 유지됩니다.

## 동작 원칙

소개 콘텐츠는 HTML만으로 읽을 수 있습니다. 자료 목록은 JSON으로 관리하며, 이미지와 코드에
base64를 넣거나 배포 시 한 HTML로 합치지 않습니다. Three.js는 갤러리가 화면 가까이 왔을 때
불러오며, 보이지 않을 때나 애니메이션이 끝나면 렌더링을 멈춥니다. WebGL을 사용할 수 없어도
일반 이미지와 이전·다음 버튼으로 같은 자료를 볼 수 있습니다. 줄어든 모션 설정을 존중합니다.

문의 버튼은 방문자의 메일 앱 또는 전화 앱을 엽니다. 서버에서 메일을 자동 발송하지 않습니다.
원본 자료는 공개본과 분리해 보관하고, 이 저장소에는 가림 처리한 공개용 사본만 넣습니다.
